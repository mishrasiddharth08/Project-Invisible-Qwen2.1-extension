# Contributing

Thank you for helping with this beginner's first public project.

## Bug reports

Use the issue template. Paste the **complete DOS/terminal error**, from the first error line through the final traceback line. Include the Forge version, GPU, model filenames, settings and exact reproduction steps.

## Changes

1. Keep each pull request focused on one problem.
2. Explain the change in simple language.
3. Do not include model weights, generated images, `_deps`, logs, tokens or private data.
4. Run the included tests when possible.
5. State exactly what you tested. Do not claim untested modes work.
6. Preserve upstream license and attribution files.

Kind, beginner-friendly explanations are welcome.
